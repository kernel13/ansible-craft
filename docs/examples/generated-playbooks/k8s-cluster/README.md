# k8s-cluster

Example Ansible playbook generated by ansible-craft for deploying a Kubernetes cluster.

## Description

This playbook deploys a production-ready Kubernetes cluster with kubeadm, including control plane nodes and worker nodes.

**Generated with:**
```bash
ansible-craft new playbook "deploy Kubernetes cluster with 3 control plane nodes and 5 workers using kubeadm"
```

## Requirements

- Target: Ubuntu 22.04 / Debian 12
- Ansible: 2.14+
- Root privileges required
- Minimum resources per node:
  - Control plane: 2 CPU, 4GB RAM
  - Worker: 2 CPU, 2GB RAM

## Variables

Key variables in `group_vars/all.yml`:
- `kubernetes_version`: Kubernetes version to install
- `pod_network_cidr`: Pod network CIDR
- `service_cidr`: Service network CIDR

## Usage

```bash
# Deploy full cluster
ansible-playbook -i inventory playbook.yml

# Deploy only control plane
ansible-playbook -i inventory playbook.yml --tags control-plane

# Deploy only workers
ansible-playbook -i inventory playbook.yml --tags workers
```
