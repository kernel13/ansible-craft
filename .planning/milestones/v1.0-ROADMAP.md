# Milestone v1.0: MVP

**Status:** SHIPPED 2026-01-21
**Phases:** 1-8
**Total Plans:** 32

## Overview

Ansible Craft v1.0 delivers an AI-powered CLI that generates production-ready Ansible roles and playbooks from natural language. The milestone progressed from foundational CLI infrastructure through core generation capabilities, quality validation, and error assistance (the killer differentiator), culminating in npm publication. Eight phases delivered a complete standalone tool that fills the gap between expensive enterprise solutions and generic AI.

## Phases

### Phase 1: Foundation

**Goal**: Users can invoke the CLI and get proper help, version info, and exit codes
**Depends on**: Nothing (first phase)
**Plans**: 3 plans

Plans:
- [x] 01-01-PLAN.md — Project scaffolding and CLI entry point
- [x] 01-02-PLAN.md — Help and version commands
- [x] 01-03-PLAN.md — Exit code handling and error display

**Details:**
- CLI displays help with usage examples via --help
- CLI displays version via --version
- CLI exits with code 0 on success, code 1 on error
- CLI displays error messages to stderr, not stdout

## Milestone Summary

**Key Decisions:**

| ID | Decision | Rationale |
|----|----------|-----------|
| Init | Standalone CLI before backend | Ship value fast, validate with real users |
| Init | User provides own API key | No backend needed for v1 |
| Init | Bun over Node | Faster builds, modern tooling |
| 03-01-01 | Pinned model version | Reproducibility |
| 04-02-03 | FQCN/idempotency as warnings | Quality guidance without blocking |
| 06-01-02 | SARIF lint format | Machine-readable, version-stable |
| 07-04-05 | --apply flag for auto-fix | Explicit opt-in for safety |
| 08-01-01 | ESM-only build | CJS incompatible with top-level await |

- None — clean development path

**Issues Deferred:**
- Web integration (WEB-01 through WEB-03) — v2 scope
- Molecule test generation (ADV-01) — v2 scope
- MCP server mode — v2 scope
- Multi-turn refinement — v2 scope
