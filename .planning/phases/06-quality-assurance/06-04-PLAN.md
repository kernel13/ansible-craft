  <action>
Create auto-fix.ts for programmatic lint violation fixes:

1. **Types**:
   ```typescript
   interface AutoFixResult {
     fixed: FixedViolation[];
     unfixable: UnfixableViolation[];
     modifiedContent: Map<string, string>; // path -> new content
   }

   interface FixedViolation {
     ruleId: string;
     file: string;
     line: number;
     original: string;
     replacement: string;
   }

   interface UnfixableViolation {
     ruleId: string;
     file: string;
     line: number;
     message: string;
     suggestion: string; // Code example of correct approach
   }
   ```

2. **FIXABLE_RULES**: Array of rule IDs we can auto-fix
   - 'fqcn' or 'fqcn[action-core]' - FQCN corrections
   - 'yaml[trailing-spaces]' - Trailing whitespace
   - 'yaml[new-line-at-end-of-file]' - Missing newline
   - 'name[casing]' - Task name casing

3. **canAutoFix(ruleId: string): boolean**
   - Return true if ruleId (or its prefix) is in FIXABLE_RULES

4. **applyAutoFixes(files: GeneratedFile[], violations: LintViolation[]): AutoFixResult**
   - Create modifiedContent Map from files (deep copy)
   - For each violation:
     - If canAutoFix: apply fix to modifiedContent, add to fixed array
     - If not fixable: add to unfixable with helpful suggestion
   - Return { fixed, unfixable, modifiedContent }

5. **Fix implementations** (internal functions):
   - **fixFqcn(content, line, module)**: Replace short module name with FQCN
     - Use BUILTIN_MODULES mapping from fqcn-checker.ts
     - Handle both task module and args: style formats
   - **fixTrailingSpaces(content)**: Regex replace /[ \t]+$/gm with ''
   - **fixNewlineAtEnd(content)**: Ensure content ends with single \n
   - **fixTaskNameCasing(content, line)**: Capitalize first letter of task names

6. **getSuggestion(ruleId: string, message: string): string**
   - Return code example suggestions for unfixable rules
   - Common patterns:
     - 'risky-file-permissions': "Use mode: '0644' instead of mode: 644"
     - 'no-changed-when': "Add changed_when: false for read-only commands"
     - 'command-instead-of-module': "Consider using ansible.builtin.copy instead of command"
