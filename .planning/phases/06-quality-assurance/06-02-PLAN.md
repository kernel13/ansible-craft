  <action>
Create progress.ts with progressive log-style phase tracking:

1. **Interface PhaseTracker**:
   ```typescript
   interface PhaseTracker {
     start(phaseName: string): void;
     succeed(message?: string): void;
     fail(message?: string): void;
     update(text: string): void;
   }
   ```

2. **createPhaseTracker(quiet: boolean): PhaseTracker**:
   - Track startTime for elapsed calculation
   - Create ora spinner (null if quiet mode)
   - Spinner config: color 'cyan', spinner 'dots', stream process.stderr

   **start(phaseName)**:
   - Record startTime = Date.now()
   - spinner?.start() with phaseName as text

   **succeed(message?)**:
   - Calculate elapsed = ((Date.now() - startTime) / 1000).toFixed(1)
   - Use stopAndPersist() with:
     - symbol: chalk.green('✓')
     - text: `${message ?? spinner?.text} ${chalk.dim(`(${elapsed}s)`)}`

   **fail(message?)**:
   - Calculate elapsed same way
   - Use stopAndPersist() with:
     - symbol: chalk.red('✗')
     - text: `${message ?? spinner?.text} ${chalk.dim(`(${elapsed}s)`)}`

   **update(text)**:
   - Update spinner.text if spinner exists

3. Export both the interface and factory function.

Import ora and chalk at top.
Use process.stderr for spinner output (keep stdout clean for piping).
