<task type="auto">
  <name>Task 1: Create preview module with syntax highlighting</name>
  <files>src/cli/preview.ts</files>
  <action>
Create preview.ts for dry-run preview functionality:

1. **Imports**:
   - `import { highlight } from 'cli-highlight';`
   - `import chalk from 'chalk';`
   - `import { confirm } from '@inquirer/prompts';`
   - `import type { GeneratedFile } from '../generation/role/parser.js';`
   - `import type { LintViolation } from '../generation/validation/ansible-lint.js';`

2. **displayFilePreview(path: string, content: string): void**
   - Print header: `console.log(chalk.cyan(`\n=== ${path} ===\n`));`
   - Print highlighted content: `console.log(highlight(content, { language: 'yaml', ignoreIllegals: true }));`
   - Handle non-YAML files (README.md) by detecting extension and using 'markdown' language

3. **displayFilesPreview(files: GeneratedFile[]): void**
   - Iterate files and call displayFilePreview for each
   - Add separator between files for readability

4. **displayLintResults(violations: LintViolation[]): void**
   - If no violations: print chalk.green('✓ ansible-lint passed')
   - If violations exist:
     - Group by file for readability
     - For each violation: `chalk.yellow(`  ${file}:${line}: [${ruleId}] ${message}`)`
     - Count errors vs warnings separately
     - Print summary: `X errors, Y warnings`

5. **previewAndConfirm(files: GeneratedFile[], lintViolations?: LintViolation[]): Promise<boolean>**
   - Call displayFilesPreview(files)
   - If lintViolations provided, call displayLintResults(lintViolations)
   - Prompt: `confirm({ message: 'Write these files?', default: false })`
   - Return boolean result

Export all functions.
