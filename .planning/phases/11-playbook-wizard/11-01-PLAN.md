   - Placeholder hint: "e.g., webservers, databases, web*:&staging"

   - First: Use @inquirer/prompts `confirm`
   - Message: "Enable privilege escalation (become)?"
   - Default: false (safer default per 11-CONTEXT.md)
   - If confirmed true: Follow up with `input` prompt
     - Message: "Become user (default: root):"
     - Empty input returns undefined (defaults to root)
   - Return object with become boolean and optional becomeUser string

3. Create `promptHandlersDescription(): Promise<string | undefined>`
   - Use @inquirer/prompts `input`
   - Message: "Describe handlers needed (or press Enter to skip):"
   - Placeholder hint: "e.g., restart nginx, reload config"
   - Optional: empty string returns undefined
   - Validate: warn (console.log dim) if input looks like YAML (contains `:` followed by newline or starts with `-`) but allow submission

Import `input`, `confirm` from @inquirer/prompts. Use chalk for styling (cyan for prompts, dim for warnings/hints).

     - become: from step 2
     - includeHandlers: true if handlersDescription provided, false otherwise
     - custom: include becomeUser and handlersDescription if provided
