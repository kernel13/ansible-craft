<task type="auto">
  <name>Task 2: Implement config loading with conflict detection</name>
  <files>
    - src/config/loader.ts
    - src/config/index.ts
  </files>
  <action>
1. Create src/config/loader.ts with loadConfig() function:
   - Check if config file exists using existsSync()
   - If exists, read and parse with smol-toml parse()
   - Read ANTHROPIC_API_KEY from process.env
   - Detect conflict: if both env var AND config file have API key AND they differ, throw CLIError with:
     - message: "API key conflict: ANTHROPIC_API_KEY and config file have different values"
     - code: "CONFIG_CONFLICT"
     - suggestion: "Remove API key from one source, or ensure they match"
   - Merge: env var takes precedence if set (no conflict means one is undefined)
   - Deep merge file config with defaults, then overlay env var API key
   - Return complete Config object

2. Add configExists() helper that returns boolean

3. Create src/config/index.ts as public API:
   - Re-export loadConfig, configExists from loader
   - Re-export Config type from schema
   - Re-export CONFIG_PATH, CONFIG_DIR from paths
   - Re-export DEFAULT_CONFIG from defaults

Use try/catch around TOML parsing with CLIError for parse failures:
- message: "Invalid config file: {parse error}"
- code: "CONFIG_PARSE_ERROR"
- suggestion: "Check TOML syntax at {CONFIG_PATH}"
  </action>
  <verify>
    - `bun run lint` passes
    - TypeScript compiles: `bunx tsc --noEmit`
    - Test no config file case:
      `ANTHROPIC_API_KEY= bun -e "import { loadConfig } from './src/config/index.ts'; const c = await loadConfig(); console.log(c.defaults.model)"`
      Should output: sonnet
    - Test env var loading:
      `ANTHROPIC_API_KEY=test-key bun -e "import { loadConfig } from './src/config/index.ts'; const c = await loadConfig(); console.log(c.api.key)"`
      Should output: test-key
  </verify>
  <done>
    - loadConfig() returns Config with defaults when no config file
    - loadConfig() reads ANTHROPIC_API_KEY from environment
    - loadConfig() throws CLIError on conflict (different keys in env and file)
    - loadConfig() throws CLIError on TOML parse error
    - index.ts exports all public config API
  </done>
