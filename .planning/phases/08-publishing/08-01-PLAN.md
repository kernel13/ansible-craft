<task type="auto">
  <name>Task 2: Create tsup configuration</name>
  <files>tsup.config.ts</files>
  <action>
Create `tsup.config.ts` in project root with configuration for dual ESM/CJS output:

```typescript
import { defineConfig } from 'tsup';

export default defineConfig({
  entry: {
    'cli/index': 'src/cli/index.ts',
  },
  format: ['esm', 'cjs'],
  dts: false, // Skip type declarations for CLI-only package
  clean: true,
  sourcemap: false, // Not needed for CLI distribution
  splitting: false, // Single file output for CLI
  treeshake: true,
  target: 'node18',
  platform: 'node',
  banner: {
    js: '#!/usr/bin/env node',
  },
  outExtension({ format }) {
    return {
      js: format === 'cjs' ? '.cjs' : '.js',
    };
  },
  // Bundle all dependencies into the output
  // Except heavy/native ones that should remain external
  noExternal: [/.*/],
  external: [],
});
```

Note: The banner adds shebang for CLI execution. The noExternal bundles everything to make npx/bunx work without node_modules.
  </action>
  <verify>
Run `cat tsup.config.ts` to confirm file exists with correct configuration.
Run `bun run build` to test the build (may fail without further changes - that's ok for this task).
  </verify>
  <done>tsup.config.ts exists with CLI entry point, dual ESM/CJS format, node18 target, and shebang banner.</done>
</task>
