<task type="auto">
  <name>Task 1: Update tsup config for proper bundling</name>
  <files>tsup.config.ts</files>
  <action>
Update tsup.config.ts to handle bundling correctly.

The key challenge: We want to bundle dependencies for npx/bunx (no node_modules), but some dependencies have issues when bundled. Use selective bundling:

```typescript
import { defineConfig } from 'tsup';

export default defineConfig({
  entry: {
    'cli/index': 'src/cli/index.ts',
  },
  format: ['esm', 'cjs'],
  dts: false,
  clean: true,
  sourcemap: false,
  splitting: false,
  treeshake: true,
  target: 'node18',
  platform: 'node',
  // Let tsup add shebang automatically for bin entries
  shims: true, // Add shims for __dirname, __filename in ESM
  // Don't bundle dependencies - they'll be installed via npm
  // This is more reliable than bundling everything
  external: [
    '@anthropic-ai/sdk',
    '@inquirer/prompts',
    'boxen',
    'chalk',
    'cli-highlight',
    'commander',
    'ora',
    'smol-toml',
    'yaml',
  ],
  esbuildOptions(options) {
    // Ensure proper handling of node built-ins
    options.banner = {
      js: '#!/usr/bin/env node',
    };
  },
});
```

Note: We keep dependencies external because:
1. They're properly declared in package.json dependencies
2. npm/npx/bunx will install them
3. Bundling can cause issues with ESM/CJS interop and native modules
  </action>
