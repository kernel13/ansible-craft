  <name>Task 1: Create system prompt with FQCN and idempotency patterns</name>
  <files>src/generation/prompts/system.ts</files>
  <action>
Create the Ansible expert system prompt that will be used for all generation calls. The prompt must:

1. **Identity**: "You are an Ansible expert generating production-ready roles"

2. **FQCN Requirement** (embed examples from RESEARCH.md):
   - Explicit rule: "Use FQCN for ALL modules"
   - Package: `ansible.builtin.apt`, `ansible.builtin.dnf`, `ansible.builtin.package`
   - File: `ansible.builtin.file`, `ansible.builtin.copy`, `ansible.builtin.template`
   - Service: `ansible.builtin.service`, `ansible.builtin.systemd_service`
   - User: `ansible.builtin.user`, `ansible.builtin.group`
   - Control: `ansible.builtin.include_tasks`, `ansible.builtin.set_fact`, `ansible.builtin.debug`
   - Command (use sparingly): `ansible.builtin.command`, `ansible.builtin.shell`

3. **Idempotency Requirement** (embed patterns from RESEARCH.md):
   - "Always specify state: parameter (present, absent, started, stopped)"
   - "Use handlers for service restarts, never inline restarts"
   - "Use creates: for command/shell when checking file existence"
   - "Never use shell for operations that have dedicated modules"
   - "Use cache_valid_time with apt to avoid unnecessary updates"

4. **YAML Formatting**:
   - 2-space indentation
   - Named tasks (every task must have name:)
   - true/false (not yes/no)
   - Quote Jinja2: "{{ variable }}"
   - Variable prefix: role_name_varname

5. **Role Structure**:
   - List all directories: tasks/, handlers/, defaults/, vars/, templates/, files/, meta/, molecule/
   - Required files: tasks/main.yml, defaults/main.yml, meta/main.yml, README.md

Export as `ANSIBLE_EXPERT_SYSTEM_PROMPT` constant string.

  <verify>`bun run typecheck` passes, file exports the constant</verify>
  <done>System prompt contains FQCN examples, idempotency patterns, and formatting rules</done>
