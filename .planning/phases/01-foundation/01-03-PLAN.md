<task type="auto">
  <name>Task 2: Configure exit codes and stderr handling</name>
  <files>src/cli/program.ts, src/cli/index.ts</files>
  <action>
Wire up exit code handling and stdout/stderr separation in the CLI.

1. Update src/cli/program.ts to add configureOutput:
   ```typescript
   program.configureOutput({
     writeOut: (str) => process.stdout.write(str),
     writeErr: (str) => process.stderr.write(str),
     outputError: (str, write) => write(formatError(str)),
   });
   ```

2. Add exitOverride to handle Commander errors:
   ```typescript
   program.exitOverride((err) => {
     // help and version display are not errors
     if (err.code === 'commander.helpDisplayed' ||
         err.code === 'commander.version') {
       process.exit(0);
     }
     // All other Commander errors exit with 1
     process.exit(err.exitCode);
   });
   ```

3. Add showHelpAfterError:
   ```typescript
   program.showHelpAfterError('(run with --help for available options)');
   ```

4. Update src/cli/index.ts error handling:
   - Import { displayError } from './output.js'
   - Import { CLIError } from '../errors/cli-error.js'
   - In catch block:
     ```typescript
     catch (err) {
       if (err instanceof CLIError) {
         displayError(err);
         process.exitCode = err.exitCode;
       } else if (err instanceof Error) {
         displayError(err);
         process.exitCode = 1;
       }
     }
     ```

5. Ensure help and version exit with code 0:
   - Help: Commander handles this, verify with exitOverride
   - Version: displayVersion should not throw, exits cleanly

6. Test error path by adding a temporary test:
   - Create a test subcommand that throws CLIError
   - Verify it displays correctly and exits with code 1
   - Remove test subcommand after verification (or keep for now)
