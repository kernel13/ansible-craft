<task type="auto">
  <name>Task 1: Initialize Bun project with dependencies</name>
  <files>package.json, tsconfig.json, biome.json</files>
  <action>
Initialize Bun TypeScript project and install dependencies.

1. Run `bun init -y` to create package.json
2. Update package.json:
   - name: "ansible-craft"
   - version: "0.1.0"
   - type: "module"
   - bin: { "ansible-craft": "./src/cli/index.ts" }
   - scripts: { "dev": "bun run src/cli/index.ts", "lint": "biome check .", "format": "biome format . --write" }

3. Install dependencies:
   - `bun add commander chalk boxen`
   - `bun add -D typescript bun-types @biomejs/biome @types/node`

4. Create tsconfig.json for Bun:
   - target: "ESNext"
   - module: "ESNext"
   - moduleResolution: "bundler"
   - types: ["bun-types"]
   - strict: true
   - skipLibCheck: true
   - noEmit: true

5. Initialize biome: `bunx @biomejs/biome init`
   - Configure for TypeScript
   - Enable format on save patterns
  </action>
  <verify>
- `bun run --version` shows Bun version
- `cat package.json` shows correct name, dependencies, bin field
- `bun run lint` runs without config errors
  </verify>
  <done>
- package.json exists with commander, chalk, boxen as dependencies
- tsconfig.json configured for Bun TypeScript
- biome.json exists for linting
  </done>
</task>

<task type="auto">
  <name>Task 2: Create directory structure and entry point</name>
  <files>src/cli/index.ts, src/cli/program.ts, src/types/cli.ts</files>
  <action>
Create the CLI directory structure and entry point.

1. Create directories:
   - src/cli/
   - src/errors/
   - src/types/

2. Create src/cli/program.ts:
   - Import Command from commander
   - Create and export `program` instance
   - Configure name: 'ansible-craft'
   - Configure description: 'Generate production-ready Ansible roles from natural language'
   - Add placeholder .version('0.1.0') - will be enhanced in Plan 02
   - Export the program

3. Create src/cli/index.ts:
   - Add shebang: #!/usr/bin/env node (node for compatibility, Bun still executes it fast)
   - Import program from ./program.ts
   - Call program.parseAsync(process.argv) in a try/catch
   - Set process.exitCode = 1 in catch block

4. Create src/types/cli.ts:
   - Define basic CLI types (can be minimal, expanded later)
   - Export empty interface CLIOptions for future use

5. Make entry point executable: `chmod +x src/cli/index.ts`
  </action>
  <verify>
- `bun run src/cli/index.ts --help` shows basic Commander help
- `bun run src/cli/index.ts --version` shows 0.1.0
- File has shebang line
  </verify>
  <done>
- src/cli/index.ts exists with shebang and is executable
- src/cli/program.ts exports configured Commander program
- Basic --help and --version work (default Commander behavior)
  </done>
</task>
