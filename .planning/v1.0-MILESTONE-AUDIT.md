## Decisions Log

Key architectural decisions made during development:

| ID | Decision | Rationale |
|----|----------|-----------|
| 08-01-01 | ESM-only build | CJS incompatible with top-level await |
| 08-02-02 | bin → dist/cli/index.js | Direct ESM execution |
| 07-04-05 | --apply flag for auto-fix | Explicit opt-in for safety |
| 06-01-02 | SARIF lint format | Machine-readable, version-stable |
| 04-02-03 | Warnings not errors | FQCN/idempotency as guidance |
| 03-01-01 | Pinned model version | Reproducibility |

See `.planning/STATE.md` for complete decision log.
